# Task 2 — Management System Website

A responsive static website based on the provided Task 2 video.

## Pages
- `index.html` — landing page with hero carousel, goal section, feature cards and call-to-action.
- `login.html` — sign-in interface with show/hide password and demo form behavior.
- `home.html` — course cards for HTML, CSS, Bootstrap and JavaScript, with working detail modals.

## Run locally
Open `index.html` in a browser. The project uses plain HTML, CSS and JavaScript; no build tools are required.

## Deploy with GitHub Pages
1. Create a GitHub repository and upload all files while preserving the `css` and `js` folders.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for the published URL and open it to verify the pages and images work.

## Notes
- Images are loaded from Unsplash, so an internet connection is required for them.
- Sign-in is only a front-end demonstration. It does not authenticate real users or store passwords.
